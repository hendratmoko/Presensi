Panduan Penggunaan

1. Pilih nama guru
2. Isi PIN pribadi 4 digit angka/huruf bebas, sebagai autentifikasi pengguna, usahakan sama setiap melakukan presensi.
3. Pilih kelas
4. Tekan tombol: S / I / A / D / T / B (D: dispensasi, T: terlambat, B: bolos)
5. Pastikan preview presensi benar
6. Tekan "Kirim Presensi" untuk record database
7. Gunakan tombol Copy Laporan Presensi Singkat/Lengkap bila ingin kirim laporan ke WhatsApp
8. Menu Data berisi grafik dan laporan
9. Login Admin untuk mengakses data tambahan
10. Scan atau kirimkan ke Bp Ibu Guru yang lain alamat berikut: www.presensi.moidea.my.id
